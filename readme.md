# Trees and Graphs

A collection of tree and graph implementations written primarily in C++ and C.

This repository contains implementations of various tree and graph algorithms and problems that I have worked on while learning and practicing these topics. It serves as a **personal reference** forimplementations for anyone who wants to learn trees/graphs.

The implementations are kept relatively straightforward and focused on understanding the underlying algorithms rather than being intended as a production-ready library.

## Topics

### Graphs

* Depth-First Search (DFS)
* Breadth-First Search (BFS)
* Cycle Detection
* Graph Traversal
* 2D Matrix Traversal
* Grid-based DFS/BFS
* More graph algorithms and problems will be added over time.

### Trees

* Tree DFS
* Tree Traversals
* Subtree Problems
* Tree-based DFS Problems
* More tree algorithms and problems will be added over time.

## Languages

* **C++** — Most implementations
* **C** — Some implementations

## Status

This repository is **continuously updated** as I learn and implement new tree and graph algorithms.
Currently, most implementations are written in **C++**, with some implementations in **C**.
If you find a bug, an incorrect implementation, or something that could be improved, feel free to point it out!
